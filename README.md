# AI-Powered Voice Cloning Detection

This project detects whether an uploaded audio file contains a real human voice or an AI-generated voice.

## Features

- Upload audio files
- Extract MFCC audio features
- Classify real and AI-generated voices
- Display detection confidence
- Streamlit-based user interface

## Technologies Used

- Python
- TensorFlow
- Librosa
- NumPy
- Streamlit

## Installation
